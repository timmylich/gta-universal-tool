Features

Everything you used to need a PC for.

🎨

Textures (texdb)

gta3, gta_int, txd, samp, mobile and menu caches with previews. Replace from PNG/JPG, export, alphamode and camnorm attributes, DXT1, DXT5, RGBA8888, RGB565, RGBA4444.

📦

IMG archives

Add, replace or delete .dff and .col files, export them, rebuild the archive to free space.

🔊

.osw audio

Listen to tracks and sounds, export them, replace them with your own mp3 and add new ones.

🚗

PC models

Port cars, skins and objects: .dff + .txd with unique texture names and no conflicts, straight into the cache and an IMG.

❄️

Retextures

Textures from a PC mod's .txd go where the game looks for them, including per-TXD copies. A whole folder at once.

💾

Backups

Every file is copied before its first change. Restore the original with one tap in Settings.

Getting started

Three steps; the built-in guide does the rest.

  1. Download the APK from Releases and install it.
  2. Allow "All files access": without it the app cannot see the game files.
  3. Pick the game folder (/SFRP64, /Brentwood, Android/data/…): the app finds it by itself.

FAQ

Do I need root or a PC?

No. Everything happens on the phone; only "All files access" is needed.

Which builds does it work with?

Mobile GTA San Andreas and SA-MP / RP server clients whose game folder has texdb/ (texture caches), .img archives and audio/.

Can it break the game?

Every file is copied to /GTAUniversalTool/backup before its first change. If the game starts crashing, open Settings → Backups and restore the original.

How do I replace a texture in mobile SA-MP?

Textures → a database (e.g. gta3) → find the texture → "Replace with image" and pick a PNG. For many textures tap "+" and pick the files: the file name is the texture name.

Does the app collect data?

No ads, analytics or accounts. The network is used only to check GitHub for a new version. Privacy policy.

How much does it cost?
