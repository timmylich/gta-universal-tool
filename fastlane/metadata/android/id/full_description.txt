<p><b>TXD Tool dan IMG Tool dalam satu aplikasi</b> untuk GTA San Andreas mobile dan klien SA-MP. Buka cache tekstur, ganti gambar, langsung main. Tanpa PC, tanpa iklan, tanpa daftar akun.</p>
<p><b>🎨 Tekstur</b></p>
<ul>
<li>Cache gta3, gta_int, samp dan lainnya dengan pratinjau, pencarian dan alias</li>
<li>Ganti atau tambah dari PNG/JPG, ekspor ke PNG, hapus</li>
<li>DXT1, DXT5, RGBA8888, RGB565, RGBA4444, mipmap, RLE</li>
<li>Batas ukuran, termasuk «seperti yang diganti», agar game tetap lancar</li>
<li>Atribut alphamode, camnorm, streammode dan atribut lain</li>
<li>Bangun ulang database untuk mengosongkan ruang setelah banyak penggantian</li>
</ul>
<p><b>❄️ Retekstur seluruh peta</b></p>
<p>Mod salju, jalan baru, rumput HD: tambahkan folder berisi .txd dan aplikasi mengerjakan sisanya. Aplikasi tahu di mana game mencari setiap tekstur, membedakan tekstur berbeda dengan nama sama dari beberapa TXD, menyimpan gambar yang sama satu kali dan melewati yang tidak diubah mod.</p>
<p><b>🚗 Mod PC</b></p>
<p>Mobil, skin dan objek (dff + txd) pindah ke mobile dalam beberapa ketukan. Beberapa model sekaligus; setiap tekstur mendapat nama unik, yang tidak terpakai dibuang.</p>
<p><b>📦 Arsip IMG</b>: tambah, ganti, ekspor dan hapus .dff, .col dan file lain; bangun ulang arsip.</p>
<p><b>🔊 Audio</b>: dengar, ekspor, ganti dan tambah trek di paket .osw.</p>
<p><b>🛡 Aman</b></p>
<ul>
<li>Setiap file game dicadangkan sebelum perubahan pertama</li>
<li>Tanpa iklan, analitik, atau akun: aplikasi tidak mengirim dan tidak mengumpulkan apa pun (hanya memeriksa versi baru di GitHub)</li>
<li>1,4 MB, sumber terbuka, gratis selamanya</li>
</ul>
<p>Panduan langkah demi langkah di dalam aplikasi. Bahasa: Bahasa Indonesia, English, Русский, Español.</p>
